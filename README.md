# 🚀 AI Task Manager

A modern full-stack task management application inspired by Microsoft To Do, built with React, Go (Gin), MongoDB, and JWT Authentication.

## ✨ Features

- 🔐 Secure User Authentication (JWT)
- 👤 User Registration & Login
- ✅ Create, Update & Delete Tasks
- 📊 Dashboard with Task Statistics
- 🔍 Search Tasks
- ⭐ Priority Management
- 📂 Category Management
- 📅 Due Dates
- 🔒 User-specific Task Management
- ⚡ RESTful API
- 🎨 Modern React UI

## 🛠 Tech Stack

### Frontend
- React.js
- JavaScript
- CSS

### Backend
- Go (Golang)
- Gin Framework
- JWT Authentication
- bcrypt

### Database
- MongoDB Atlas

## 🚀 Getting Started

### Backend

```bash
cd backend
go mod tidy
go run main.go
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
